# Agent rules

## Skill routing

- Concrete skills are silent; navigators route to them. Navigators:
  - `dev-nav`: the dev lifecycle card book
  - `dev-flow-nav`: parallel agents, subagent spawning and delegation
  - `design-nav`: UI design, prototypes, shadcn, diagrams
  - `ops-nav`: tools, Confluence, coordination, writing
  - `knowledge-nav`: repository evidence and the repoWiki
- When installing a new skill, tool, or extension: read `integrate-capability`.
