# 10 Codify

Phase gate: you cannot leave phase 10 without the artifact below.
Skill: `~/.pi/agent/git/github.com/obra/superpowers/skills/writing-skills/SKILL.md`

## Enter

- The work taught something the next agent would otherwise re-derive.
- A skill is being created, edited, or verified before deployment.

## Exit artifact

An amended or new skill that was first watched failing without it (pressure scenarios against a
baseline), then watched passing with it. The skill file alone is not the artifact; the two
observations are.

## Earns its place

- **Prevents:** the same lesson re-derived by the next agent, at full cost, every time.
- **Evidence:** the skill's own core principle is the measure: "Writing skills IS Test-Driven
  Development applied to process documentation. If you didn't watch an agent fail without the
  skill, you don't know if the skill teaches the right thing."

## Why this closes the cycle

This is the only card that amends the deck. Everything the other nine phases learned becomes
cheaper for the next run at phase 1 only if it lands here. Without this phase the loop is a
straight line that resets after every task, and agent ability does not compound.

## Not this card

- A card that failed to route is an admission-test failure *in this deck*, fixed in this deck, not
  patched with a new skill.

## Handoff

This card amends phase 1's deck. If the change is to this deck itself, re-run the admission test in
`SKILL.md` and the routing fixture in `evals/`.
