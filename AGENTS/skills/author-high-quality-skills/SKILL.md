# Author High-Quality Skills

## Purpose

Create or revise skills that are short, clear, reusable, and verifiable.

## When to Use

Use this skill when:

- creating a new local skill
- revising an existing local skill
- tightening a skill that is too long or vague
- moving detailed instructions out of a bloated root `SKILL.md`

## Process

1. Define the skill job and trigger conditions.
2. Read `references/skill-structure.md`.
3. Read `references/skill-frontmatter.md`.
4. Write or revise the root `SKILL.md` as a short instruction list.
5. Read `references/skill-writing-rules.md` and move detailed instructions into focused reference files.
6. Read `references/skill-verification.md` and verify the skill on a realistic task.
7. Read `references/skill-review-checklist.md` and tighten the skill before finishing.

## Progressive Disclosure Rule

- The root `SKILL.md` routes the skill.
- Detailed instructions belong in reference files.
- Reference files should be one level deep under `references/`.
- Load only the reference files needed for the current task.

## Constraints

- Do not turn the root `SKILL.md` into a long essay.
- Do not keep detailed procedures only in the root file.
- Do not add extra docs such as `README.md`, `QUICK_REFERENCE.md`, or `CHANGELOG.md`.
- Do not finish without running the verification and review steps.
