# Skill Review Checklist

Review the skill before finishing.

Checklist:

- The skill job is clear.
- Trigger conditions are explicit.
- The frontmatter `description` says when to use the skill, not what it does.
- The root `SKILL.md` is short and procedural.
- Detailed instructions are in focused reference files.
- Reference files are one level deep and narrowly scoped.
- There are no extra docs like `README.md` or `CHANGELOG.md`.
- The skill was verified on a realistic task.
- The skill can be reused without extra explanation.
- The files are lean and do not repeat each other.
