# Skill Verification

Do not finish a skill without verifying it on a realistic task.

Verification steps:

1. Pick one realistic task that should trigger the skill.
2. Check that the root `SKILL.md` is enough to route the work.
3. Load only the needed reference files.
4. Confirm the skill gives enough instruction to complete the task.
5. Record any confusion, missing steps, or bloated sections.
6. Revise the skill and rerun the same task.

Verification checks:

- the trigger conditions are clear
- the root file stays short
- the needed details exist in reference files
- the skill can be used without extra explanation
- no irrelevant files were required

Fail the skill if:

- the root file tries to teach everything itself
- the task cannot be completed from the instructions
- the skill depends on unstated assumptions
- the skill requires unrelated context to make sense
